Competitor check (Google: FDown/GetVidFB/Apify/scripts): the standard technique = fetch each sibling's **`photo.php?fbid={photoId}`** page and take ITS og:image (full-res) — photo IDs are the FIRST numeric segment of the CDN path (`{photoId}_{fbid}_{…}_n.jpg`).
- **FIXES in `src/lib/facebook.ts`:**
  - `extractPhotosFromHtml` → returns `PhotoCandidate[]` (`{url, alt}` = promoted + raw original). Dedupe by URL path now keeps the **best rendition** per photo via new `photoQualityScore(u)` (jpg/png +10 vs webp +1; adds `s/p` stp dims, `ctp=p{w}x{h}`, `cstp=mx{w}x{h}`, `/p{w}x{h}/` path dims; an unsigned `dst-jpg` with NO size token = ORIGINAL → +2000).   - `promotePhotoUrl` now also upgrades `stp=dst-webp_q70_s{N}x{N}` → `stp=dst-jpg_p2048x2048` (was jpg-only). Downloaders retry the raw `alt` URL when the promoted URL 403s (signed/locked) — **no photo is ever lost to a promotion**.
  - New `photoIdFromUrl(u)` (first numeric CDN segment) + `isThumbOnly(u)` (quality < `MIN_FULL_PHOTO_SCORE = 320`).
  - New `fetchSiblingPhotosFull(ids)`: per-photo `photo.php?fbid={id}` matrix (web. iPhone → www. desktop → m. iPhone, 6s timeout each) in 3 parallel rounds, only for ids still missing; takes the page's og:image (rejects login/static/facebook.com URLs), promotes it, replaces the thumb in the set. `fetchFacebookPhotoSet` triggers this only when thumb-only siblings exist (flagged IPs: all rounds fail fast → thumbs kept; unflagged IPs: round 1 yields the full og:image).
