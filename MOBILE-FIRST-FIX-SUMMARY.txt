*** FIX 1: Mobile Comparison Tables Clipped (25 files, 26 wrappers) ***

  Problem:
    Tool pages ki comparison tables (.cmp-table) mobile pe 40px left se kat
    rahi thi. 360px viewport pe table ka effective window sirf ~280px bacha
    tha aur body { overflow-x: hidden } unhe cut kar deta tha.

  Fix:
    Har table ko scroll container me wrap kiya with this exact class string:

      overflow-x-auto -mx-10 px-4 w-[calc(100%_+_5rem)] sm:mx-0 sm:px-0 sm:w-full

    (components me ye "cmp-table-wrap" class ke saath:
     "cmp-table-wrap overflow-x-auto -mx-10 px-4 w-[calc(100%_+_5rem)] sm:mx-0 sm:px-0 sm:w-full")

    - overflow-x-auto  = table andar scroll hoti hai, layout nahi tootta
    - -mx-10 (-40px)   = section padding 16px + .container-page 24px EXACTLY
                         cancel karta hai -> wrapper mobile pe poora [0..360]
    - px-4             = scroll karte waqt left/right breathing room
    - sm: (600px)      = 600px+ pe wapas normal (mx-0, px-0, w-full)
                         -> DESKTOP LAYOUT BILKUL UNCHANGED
    - w-[calc(100%_+_5rem)] = full-bleed width jo -mx-10 ko compensate karta hai

  Kyun literal "-mx-4 px-4 w-full" NAHI use kiya:
    border-box me width:100% content box (280px) ke against resolve hota hai,
    isliye -mx-4 w-full se scroller 248px ka reh jata (pehle se bhi BURA).
    -mx-10 (-40px) hi 16+24px padding ko exactly cancel karta hai.

  Also removed:
    Components (FbComparisonSection / ComparePage) me scoped CSS se
    "width: 100%" hataya - wo negative-margin bleed ko override kar raha tha.

*** FIX 2: Nav Links Clipping 601-1399px (1 file) ***

  Problem:
    .nav-links { overflow: auto hidden; min-width: 0 } flex row ko shrink kar
    deta tha. Links ka intrinsic width ~670px tha, aur worst locale (German CTA
    cluster 341px) ke saath har width 601px -> ~1216px pe links kat rahe the.

  Fix (src/components/NavBar.astro):
    NavBar me RAW px media queries hain - Tailwind variants (md:/lg:) ka wahan
    koi asar nahi hota, isliye seedha px values change ki:

      PEHLE:  @media (max-width: 1399px) and (min-width: 601px) { ... }
      AB:     @media (max-width: 1399px) and (min-width: 1280px) { ... }

      PEHLE:  @media (max-width: 600px)  { links hidden, hamburger ON }
      AB:     @media (max-width: 1279px) { links hidden, hamburger ON }

    Result:
      601-1279px -> hamburger + mobile menu (links clip nahi hote)
      1280px+    -> desktop links (box 671-683px >= intrinsic 671, no clip)

    Note: breakpoint 1279/1280 (1024 nahi) isliye chuna kyunki German locale
    ko 1216px+ chahiye tha; project ke breakpoints hain sm=600, md=960,
    lg=1200, xl=1400. 1280 = sabse safe round number.

  Files changed:
    src/components/NavBar.astro
